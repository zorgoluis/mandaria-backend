# V1.18 — handoff WEB (backend local; interfaz pendiente)

Base `/api/v1/customer/delivery-requests/{publicId}`. JWT CUSTOMER vigente, cuenta activa y correo verificado; ownership MDR obligatorio. Administrador del proveedor/SUPER_ADMIN no reciben GPS por estos endpoints.

| Método/sufijo | Entrada | Resultado |
|---|---|---|
| GET `/location` | Sin cuerpo | 200 LocationViewResponse |
| GET `/tracking-link` | Sin cuerpo | 200 TrackingLinkResponse sin secreto |
| POST `/tracking-link` | Idempotency-Key UUID; `{expectedLinkRevision:"1"}` | 201 primera emisión con URL; 200 replay sin URL |
| POST `/tracking-link/revoke` | UUID nuevo; `{expectedLinkRevision:"2"}` | 200 metadata; conflicto409 obliga consultar |
| GET `/tracking-link/attempt` | Idempotency-Key original; query `operation=ISSUE|REVOKE&expectedLinkRevision=1` | 200 TrackingAttemptResponse |

Metadata: `linkRevision, linkId, status, createdAt, expiresAt, terminalAccessUntil`; status NONE/ACTIVE/EXPIRED/REVOKED/TERMINAL. Mantener únicamente marcador `{publicId,operation,key,expectedLinkRevision,actor}`. No guardar URL/token/cuerpos. Recuperación y cierre explícito según [contrato](V1.18-LOCATION-IMPLEMENTATION.md#enlace-y-recuperación); SUPERSEDED no acredita ausencia histórica de efectos. Nunca nueva emisión automática.

Pantalla destinatario propuesta `/track#t=selector.secret`: extraer fragmento a memoria y retirarlo antes de cargar terceros. GET `/api/v1/shared/delivery-tracking`, cabecera `Authorization: Tracking selector.secret`, **sin token en URL API**, query, storage, cookie, logs, referer o analítica. Recargar después de borrar fragmento requiere abrir el enlace original. No service-worker cache ni caché compartida. No enviar JWT del integrador al navegador. CORS sólo origen WEB autorizado.

Usar `location.sample` sólo cuando AVAILABLE y no superó eraseAfter. Mostrar RECENT/STALE y atención operativa; retirar marcador en cambio de generación, terminal, error de autorización/revocación o caducidad local. GPS comienza para titular en TO_PICKUP; destinatario en PICKED_UP. No mostrar mapa histórico ni deducir cobro/entrega de coordenadas. No restaurar coordenada desde respuesta con versiones inferiores: comparar publicVersion y locationVersion por MDR con BigInt, conservar el watermark terminal/generación y esperar fotografía coherente. Límite: una respuesta ya autorizada antes de revocar no puede retirarse de la red; polling no es revocación instantánea de bytes previamente recibidos.

Errores:400 validación,401 JWT,403 permisos/scopes,404 MDR ajena/inexistente o SHARED_TRACKING_UNAVAILABLE genérico,409 LINK_REVISION_CONFLICT/LINK_NOT_ISSUABLE/IDEMPOTENCY_KEY_REUSED,429 con Retry-After,503 flags/indisponibilidad. La API no confirma ninguna operación física al consultar/revocar.

Resincronizar `openapi.json`. Faltan implementación visual, consentimiento/permisos del dispositivo, comprobación de analítica/headers en hosting real y pruebas de integración. No se modificó frontend.
