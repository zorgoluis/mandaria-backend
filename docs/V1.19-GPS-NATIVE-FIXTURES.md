## Herramienta y evidencia

Desde raíz backend:

```powershell
node scripts/prepare-native-v119-gps.mjs start
node scripts/prepare-native-v119-gps.mjs snapshot
node scripts/prepare-native-v119-gps.mjs stop
```

Start/stop identifican puerto, PID/launcher, SQL y datadir antes de operar; conservan datos. `init` es sólo para directorio nuevo y puertos libres. `prepare` persiste pasos/claves y bloquea resultados inciertos; una vez completo sólo verifica y no duplica. `verify` exige estado inicial y debe fallar tras consumo Android: usar snapshot para deltas, no reabrir ni resetear.

Snapshot: once tablas operativas más IndependentDispatchAttempt, DeliveryTrackingLinkHead y LocationRateBucket separados; conteos/huellas y metadata stream/secuencia/versiones, sin coordenadas/tokens. Las lecturas GPS consumen cuotas y pueden inicializar sincrónicamente trackingEnabled; no exigir igualdad de esas tablas entre lecturas. GPS puro no cambia hitos, ledger, custodia ni declaración; REPORT/transferencia/DELIVER sí generan deltas legítimos. Auth/refresh se evalúan aparte.

Pendientes APP: conexión emulador, muestras, carreras/timeout/reinicio, invalidaciones y capturas visuales sin secretos. Diferenciar ubicación simulada de emulador de captura física; no acredita dispositivo físico, UNKNOWN, independent=null ni VEHICLE_BUSY aislado. No cambios de producto ni activación remota.
