# V1.18 — handoff B2B / portal

Backend implementado en checkout local; disponibilidad en QA remota/producción **no acreditada**. Resincronizar `docs/openapi-b2b.json`. API confirmada https://mandaria.com.mx/api/v1; OpenAPI servers.url conserva https://mandaria.com.mx porque paths ya llevan `/api/v1`.

Nuevas operaciones revisadas explícitamente:

| Método y ruta (prefijo `/api/v1`) | Scopes, todos requeridos |
|---|---|
| GET `/delivery-requests/{publicId}/location` | deliveries:read + deliveries:location:read |
| GET `/delivery-requests/{publicId}/tracking-link` | deliveries:read + deliveries:tracking-links:manage |
| POST `/delivery-requests/{publicId}/tracking-link` | iguales |
| POST `/delivery-requests/{publicId}/tracking-link/revoke` | iguales |
| GET `/delivery-requests/{publicId}/tracking-link/attempt` | iguales |

Ownership IntegrationClient en todas; no se conceden scopes nuevos automáticamente. JWT B2B separado de JWT humano y del token destinatario. Cuerpos, códigos y recuperación idénticos a [WEB](V1.18-WEB.md), con actor de recibo = credencial B2B utilizada. Otra credencial del mismo cliente puede administrar el enlace actual pero no acreditar recibos ajenos; mantener revisión original para impedir POST tardío.

Ejemplo **ficticio**, campos reales de LocationViewResponse:

```json
{"publicId":"MDR-000123","progress":{"publicVersion":"42","status":"ASSIGNED","trackingMode":"DETAILED","assignmentState":"ACTIVE","phase":"TO_DROPOFF","attentionRequired":false,"terminalOutcome":null},"location":{"locationVersion":"19","assignmentGeneration":"5","availability":"AVAILABLE","unavailableReason":null,"sample":{"latitude":17.02,"longitude":-93.37,"accuracyMeters":12,"capturedAt":"2026-10-06T18:00:00.000Z","receivedAt":"2026-10-06T18:00:02.000Z","freshUntil":"2026-10-06T18:01:00.000Z","eraseAfter":"2026-10-06T18:10:00.000Z"}},"observation":{"evaluatedAt":"2026-10-06T18:00:03.000Z","freshness":"RECENT"}}
```

Sin GPS: sample:null, availability:UNAVAILABLE; razones NO_ASSIGNMENT/NO_SAMPLE/NOT_VISIBLE/LEGACY_UNSUPPORTED/EXPIRED_SAMPLE/TERMINAL/TRACKING_DISABLED. Sólo esta proyección mínima se comparte; no incluye IDs internos, ejecutor privado, contactos, motivos de incidencia o pagos. Consultar `/status` existente para identidad pública autorizada del ejecutor; no cambia su contrato.

Polling desde backend integrador con resultado compartido; objetivo15s condicionado a cuota agregada (60/min propietario, además del limitador IP existente). 4N lecturas/min, más otras consultas; no hay capacidad simultánea aprobada. Backoff+jitter, Retry-After, pausar entregas no observadas y terminar al confirmar terminal. Mantener watermarks por MDR/audiencia; no mezclar progreso viejo con ubicación nueva ni restaurar posición de generación anterior. No basarse sólo en orden de llegada HTTP.

Conservar `delivery.completed` y reconciliar por consulta: no hay nuevos eventos GPS ni garantía tiempo real. URL de enlace se muestra sólo una vez; no registrar/analizar/retransmitir automáticamente a WhatsApp/SMS. Faltan pantalla destinatario e integración de consumidor, no forman parte de backend.

Generar/verificar: `npm run docs:b2b`, `npm run docs:b2b:check`, `npm run test:public-b2b`. No publicar OpenAPI completo como sustituto: rutas humanas/Driver/admin/shared quedan fuera del artefacto B2B.
